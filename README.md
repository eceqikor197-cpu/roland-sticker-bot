## 🌟 Что это и ключевые возможности

1. **Telegram-бот для клиентов и печатников**:
   - Приём изображений любого формата (JPEG, PNG, WEBP, TIFF, BMP) без потери исходного качества (Lossless Print & Cut).
   - Умное удаление фона и белых полей с анализом силуэта в цветовом пространстве CIE L\*a\*b\*.
   - Интерактивная настройка отступа контура (CutContour) от 0 мм до 10+ мм с плавным скруглением углов.
   - Независимое масштабирование и компенсация усадки плёнки (`stretch_x`, `stretch_y`).
   - Автоматический расчет оптимального спуска тиража на рулон (500 мм, 1370 мм и др.) или на стандартный лист А4 (210×297 мм).
   - Динамический расчёт себестоимости и коммерческой стоимости заказа (`pricing.py` + `pricing.toml`).
   - Отправка в Hot Folder плоттера Roland VersaWorks с валидацией прав доступа.

2. **Двойной векторный контур резки**:
   - **`CutContour` (надсечка виниловой плёнки)**: специальный плашечный спот-цвет Roland (`100% Spot Magenta`, линия `0.25 pt`), прорезающий винил до подложки.
   - **`PerfCutContour` (сквозная вырубка стикера)**: спот-цвет Roland (`100% Spot Cyan`, линия `0.25 pt`), прорезающий стикер насквозь вместе с силиконизированной бумагой.
   - **Многопроходная вырубка (Multi-pass Perf-Cut)**: поддержка 1x, 2x и 3x проходов ножа плоттера со субпиксельным микросмещением (1.4 мкм), предотвращающим схлопывание дубликатов в RIP.

3. **Веб-панель оператора (Web Admin)**:
   - Мониторинг загруженных заданий, очереди печати, пользователей и дискового пространства.
   - Защита сессий, защита от брутфорса, токены против CSRF и безопасные заголовки.
   - Управление live-шпионом активности пользователей и модерация заданий.

4. **Высоконадежное локальное хранилище**:
   - База данных SQLite с включённым режимом журналирования **WAL** (Write-Ahead Logging).
   - Потокобезопасная запись через `threading.Lock` и thread-local соединения.
   - Автоматический фоновый сборщик мусора (удаление файлов старше заданного срока по GDPR / Privacy).

```

│   ├── keyboards.py               # Генераторы инлайн-клавиатур и меню раскладки
```

## 🚀 Установка

### 1. Системные требования

- **Python**: версия `3.12` или новее (проверено на Python 3.12 и Python 3.13).
- **ОС**: macOS, Linux (Ubuntu 22.04+ / Debian 12+) или Windows (WSL2).
- **Системные библиотеки**: стандартная библиотека C для OpenCV (`libgl1` на headless Linux серверах при необходимости).

### 2. Пошаговая установка

```bash
# Клонируйте репозиторий
git clone https://github.com/cryfcknbaby/roland-sticker-bot.git
cd roland-sticker-bot

# Создайте и активируйте виртуальное окружение
python3.12 -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# .venv\Scripts\activate   # Для Windows

# Обновите pip и установите зависимости проекта
pip install --upgrade pip
pip install -r requirements.txt

# (Опционально) Установите инструменты для разработки и тестов
pip install -r requirements-dev.txt
```

## 🖥️ Запуск бота и веб-админки

Точкой входа является файл [telegram_bot.py](file:///Users/danilakonovalov/Documents/antigravity/hopeful-bohr/telegram_bot.py). При запуске он:
1. Инициализирует базу данных SQLite и миграции схемы.
2. Запускает фоновый поток очистки устаревших файлов (`storage/cleanup.py`).
3. Запускает HTTP-сервер веб-админки (`web/server.py`) в фоновом потоке.
4. Регистрирует команды меню Telegram и запускает поллинг (`bot/runner.py`).

```bash
# Стандартный запуск
python telegram_bot.py
```

### Запуск в качестве системной службы (systemd на Linux)

Создайте файл `/etc/systemd/system/roland-bot.service`:

```ini
[Unit]
Description=Roland Plotter Telegram Bot & Web Admin
After=network.target

[Service]
Type=simple
User=roland
WorkingDirectory=/opt/roland-sticker-bot
ExecStart=/opt/roland-sticker-bot/.venv/bin/python telegram_bot.py
Restart=always
RestartSec=5
EnvironmentFile=/opt/roland-sticker-bot/.env

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now roland-bot
```

## 🔒 Безопасная схема доступа к админке

В соответствии с правилами безопасности веб-админка **не должна быть открыта наружу в публичный интернет** без шифрования и авторизации.

### Рекомендуемая архитектура подключения

```
[ Рабочее место оператора ]
           │
           │  (Безопасный туннель: Tailscale / WireGuard / SSH Port Forwarding)
           ▼
[ Сервер печати (Linux/Mac) ]
     ├── 127.0.0.1:8090 (AdminWebHandler, сессии, CSRF, Anti-Bruteforce)
     ├── SQLite (bot_storage.db, WAL-режим)
     └── Сетевая папка плоттера (Hot Folder Roland VersaWorks)
```

### 1. Доступ через SSH-туннель (Рекомендуется)
Веб-сервер слушает только локальный интерфейс `127.0.0.1:8090`:
```bash
# На локальном компьютере оператора выполните:
ssh -N -L 8090:127.0.0.1:8090 user@ip-сервера-печати
```
После этого веб-панель открывается в браузере по адресу: **`http://localhost:8090`**.

### 2. Доступ через частную сеть (Tailscale / Netbird / WireGuard)
При использовании VPN установите `ADMIN_WEB_HOST` равным IP-адресу сервера в оверлейной сети (например, `100.x.y.z` в Tailscale). Доступ будет возможен только авторизованным узлам вашей сети.

### 3. Механизмы защиты веб-панели
- **Защита от подбора пароля (Rate Limiting)**: при неудачных попытках входа срабатывает прогрессивная блокировка IP-адреса.
- **Безопасные Cookies**: сессионный токен передаётся с флагами `HttpOnly` и `SameSite=Strict`.
- **Защита от CSRF**: все формы изменения настроек и действий над макетами снабжены валидируемым криптографическим токеном `csrf_token`.
- **Изоляция Hot Folder**: проверка на отсутствие атак Path Traversal (`../`). Обычные пользователи не могут записать произвольный файл в очередь плоттера.

## 🛠️ Автономный CLI-конвертер `jpeg2eps`

Конвертер [`jpeg2eps.py`](file:///Users/danilakonovalov/Documents/antigravity/hopeful-bohr/jpeg2eps.py) может использоваться абсолютно автономно без запуска бота для ручной подготовки макетов из командной строки.

### Примеры использования:

```bash
# 1. Базовая конвертация (растр -> EPS с контуром реза 2.5 мм):
python jpeg2eps.py sticker.png

# 2. Задать точный физический размер (80 мм) и отступ контура (3 мм):
python jpeg2eps.py sticker.png --size-mm 80 --offset-mm 3.0

# 3. Не вырезать фон (сохранить изображение целиком):
python jpeg2eps.py badge.jpg --keep-bg --size-mm 50

# 4. Дополнительно сохранить векторное превью в формате SVG:
python jpeg2eps.py sticker.png --svg

# 5. Пакетная конвертация всех изображений в папке с выводом в другую директорию:
python jpeg2eps.py ./raw_stickers/ -o ./ready_eps/
```

### Параметры CLI `jpeg2eps`:

| Аргумент | По умолчанию | Описание |
| :--- | :--- | :--- |
| `inputs` | — | Пути к файлам (JPEG/PNG/WebP/BMP/TIFF) или папкам. |
| `-o`, `--output-dir` | рядом с файлом | Директория для сохранения готовых `.eps` файлов. |
| `--size-mm` | `100.0` | Физический размер большей стороны стикера в миллиметрах. |
| `--offset-mm` | `2.5` | Отступ контура реза `CutContour` вокруг объекта в мм (`0` = в край). |
| `--bg-tolerance` | `12.0` | Порог чувствительности удаления внешнего фона с краев. |
| `--keep-bg` | `false` | Не удалять фон изображения. |
| `--no-cut-contour` | `false` | Не генерировать контур реза `CutContour`. |
| `--contour-only` | `true` | Сохранить полноразмерный оригинальный растр + векторный контур. |
| `--svg` | `false` | Дополнительно создать файл `.svg` для быстрого просмотра в браузере. |
| `--notify` | `false` | Показать созданный файл в Finder macOS и воспроизвести сигнал. |

## 🖨️ Интеграция с Roland VersaWorks

Готовые EPS-файлы полностью соответствуют спецификации Adobe PostScript 3.0 EPSF-3.0 с бинарным заголовком DOS EPS и встроенным TIFF-превью:

1. Откройте **Roland VersaWorks**.
2. В свойствах очереди (**Queue A Properties** или **Queue B Properties**) перейдите во вкладку **Quality**.
3. Убедитесь, что активирован режим печати и резки (**Print & Cut**).
4. VersaWorks автоматически распознаёт плашечные цвета:
   - **`CutContour`** — отображается мигающим пунктирным контуром надсечки винила.
   - **`PerfCutContour`** — отображается как линия сквозной перфорации.
5. Для полностью автоматической отправки укажите сетевой путь к папке очереди VersaWorks (Hot Folder) в настройках сервера.

## 🛡️ Приватность и безопасность

- **GDPR / Удаление данных**: пользователи бота могут в любой момент удалить все свои загруженные макеты, историю и настройки командой `/delete_my_data`.
- **Автоматическая ротация**: фоновый воркер удаляет временные файлы и выполненные работы старше `JOB_RETENTION_HOURS` (по умолчанию 7 дней).
- **Политика раскрытия уязвимостей**: подробно описана в файле [SECURITY.md](SECURITY.md).
