# 🖨️ Roland Sticker Bot & Harvester (`jpeg2eps`)

Комплексная автоматизированная система подготовки, генерации и печати стикеров для широкоформатных плоттеров **Roland VersaCAMM VP-540** (и других плоттеров с поддержкой RIP **Roland VersaWorks**, Mimaki RasterLink, Graphtec, FlexiSIGN).

Включает в себя:
1. **Telegram-бот**: интерактивная подготовка макетов с точными физическими размерами, отступами и линиями реза.
2. **Векторный движок `jpeg2eps`**: конвертация растра в чистый PostScript EPS 3.0 с плашечными спотовыми цветами `CutContour` и `PerfCutContour`.
3. **Автоматический комбайн (Sticker Harvester)**: автономный сбор стикеров из сети, разделение паков на отдельные наклейки, фильтрация качества и генерация каталога.
4. **Интерактивная веб-панель**: браузерная витрина базы стикеров с мгновенным поиском, предпросмотром и скачиванием готовых EPS.
5. **Интеграция с Roland VersaWorks**: горячие папки (Hot Folders) для мгновенной отправки макетов в очередь печати/резки.

---

## 🌟 Ключевые возможности

### 1. Двойной контур резки (Kiss-Cut + Perf-Cut)
- **`CutContour` (Прорез до подложки)**: стандартный спотовый цвет Roland (`100% Spot Magenta`, `0.25 pt`). Прорезает только виниловую плёнку, оставляя бумажную подложку целой.
- **`PerfCutContour` (Сквозной рез / Перфорация)**: спотовый цвет Roland (`100% Spot Cyan` / `PerfCutContour`). Прорезает наклейку насквозь вместе с подложкой.
- **Многопроходный сквозной рез (Multi-pass Perf-Cut)**: для толстых плёнок и ламинации поддерживается 1x, 2x и 3x прохода. Каждый дополнительный проход смещается ровно на 1.4 микрона (`0.004 pt`), благодаря чему нож идёт строго по той же колее, а RIP не схлопывает пути как дубликаты.

### 2. Telegram-бот управления печатью
- **Приём любых изображений**: JPEG, PNG, WEBP, а также несжатые файлы и документы.
- **Умное удаление фона**: удаление белого и сплошного фона с анализом в цветовом пространстве `CIE L*a*b*`.
- **Настройка отступов и белого канта**: отступ контура от 0 мм (в край) до 10+ мм с плавным скруглением углов.
- **Пакетная раскладка**: компоновка на стандартные рулоны винила (500 мм, 1370 мм и др.) с оптимизацией расхода материала.
- **Прямая отправка в Hot Folder**: сохранение EPS сразу в сетевую папку RIP-станции Roland.

### 3. Автоматический комбайн стикеров (Sticker Harvester)
- **Многопоточный краулер**: сбор стикеров по 150+ поисковым категориям (автонаклейки, аниме, мем-паки, бренды, каллиграфия и др.).
- **Pack Splitter**: автоматический поиск связанных компонент на сборных листах и нарезка стикерпаков на отдельные наклейки.
- **Quality Gate (Контроль качества)**:
  - Фильтрация по минимальному разрешению и резкости.
  - Детекция артефактов JPEG-сжатия.
  - Дедупликация на основе перцептивных хешей (`pHash` через `ImageHash`).
- **Синхронизация хранилища**: автоматический экспорт через `rclone` в облачные диски или на сетевое хранилище плоттера.

### 4. Веб-дашборд и дерево каталога
- 3-уровневая иерархическая структура:
  1. **Раздел** (`01_Стикерпаки`, `02_Авто_Наклейки`, `03_Одиночные_Стикеры`, `04_Баннеры_и_Вывески`).
  2. **Подкатегория** (JDM, Offroad, Мемы, Бренды и т.д.).
  3. **Коллекция / Папка** с карточками стикеров.
- Интерактивный веб-интерфейс (`/harvester`) с мгновенным поиском по названиям и тегам.
- Автоматический публичный защищённый туннель с авто-обновлением кнопки доступа в Telegram-боте.

## 🚀 Быстрый старт

### 1. Установка зависимостей

Требуется **Python 3.10+**.

```bash
# Клонирование репозитория
git clone git@github.com:eceqikor197-cpu/roland-sticker-bot.git
cd roland-sticker-bot

# Создание и активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `.env` на основе примера:

```bash
cp .env.example .env
```

Укажите в `.env` токен вашего Telegram-бота (полученный у [@BotFather](https://t.me/BotFather)):
```env
PLOTTER_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
```

### 3. Запуск Telegram-бота и веб-панели

```bash
python telegram_bot.py
```

После запуска бот готов принимать изображения в Telegram, а локальная веб-панель доступна по адресу `http://localhost:8090/harvester`.

## 🛠️ Использование CLI `jpeg2eps`

Конвертер можно использовать автономно из командной строки для одиночных файлов и целых папок:

```bash
# 1. Базовая конвертация (растр -> вектор EPS с контуром CutContour 2.5 мм):
python jpeg2eps.py sticker.png

# 2. Только векторный контур вокруг исходного растра (для сохранения фотореализма):
python jpeg2eps.py photo.jpg --contour-only

# 3. Задать точный физический размер (80 мм) и отступ контура (3 мм):
python jpeg2eps.py sticker.png --size-mm 80 --offset-mm 3.0

# 4. Двойной рез: прорез до подложки + сквозная перфорация в 2 прохода:
python jpeg2eps.py sticker.png --perf-cut --perf-cut-passes 2

# 5. Пакетная обработка целой папки:
python jpeg2eps.py ./incoming_art/ -o ./ready_for_rip/
```

### Основные аргументы CLI:
- `-o`, `--output-dir` — папка для готовых EPS файлов.
- `--size-mm` — размер большей стороны стикера в миллиметрах (по умолчанию `100.0`).
- `--offset-mm` — отступ линии `CutContour` в мм (`0` — рез строго по рисунку).
- `--contour-only` — не векторизовать картинку внутри, сохранить исходный растр высокого разрешения + наложить векторный `CutContour`.
- `--perf-cut` — добавить внешний контур сквозной перфорации `PerfCutContour`.
- `--perf-cut-passes` — количество проходов сквозного реза (`1`, `2` или `3`).
- `--bg-tolerance` — порог чувствительности авто-удаления фона (по умолчанию `26.0`).
- `--svg` — дополнительно сохранить файл `.svg` для быстрого просмотра в веб-браузере.

## 🖥️ Интеграция с Roland VersaWorks

1. Откройте **Roland VersaWorks**.
2. В меню выберите **Queue A** (или **Queue B**) → **Queue Properties** → закладка **Quality**.
3. Убедитесь, что в свойствах задания включена опция **Cut**:
   - `CutContour` распознаётся автоматически как линия реза плёнки.
   - `PerfCutContour` активирует режим перфорационного реза плоттера (VP-540, VG, SG и др.).
4. Для автоматической печати укажите путь к сетевой папке в боте как Hot Folder.
