# Единицы измерения и система координат (COORDINATES.md)

Единый контракт геометрических вычислений для бэкенда (`sticker_app`), фронтенда (`web`) и модуля экспорта на плоттер (`export`).

---

## 1. Фундаментальный принцип

> **Единственный источник истины — миллиметры (`mm`).**
> Пиксели существуют исключительно внутри графического отображения на экране пользователя (Canvas / Stage) и зависят от масштаба экрана (zoom) и разрешения дисплея.

Все расчёты раскладок, проверка пересечений, ограничения полей объектов, расчёт авторасстановки (compose) и экспорт для плоттера выполняются **строго в миллиметрах** с точностью чисел с плавающей запятой (`float`).

---

## 2. Система координат объекта

1. **Начало координат `(0, 0)`:**
   - Левый верхний угол габаритного прямоугольника целевого объекта (например, крышки ноутбука).
2. **Направление осей:**
   - Ось **X** направлена **вправо** (значения растут слева направо: от `0` до `object.width_mm`).
   - Ось **Y** направлена **вниз** (значения растут сверху вниз: от `0` до `object.height_mm`).
   - *Примечание для экспорта (EPS/PDF):* при формировании PostScript-файлов ось Y плоттера направлена снизу вверх (`Y_eps = PageHeight - Y_canvas`). Преобразование инкапсулировано внутри адаптера экспорта.
3. **Позиция стикера `(x_mm, y_mm)`:**
   - Координаты `(x_mm, y_mm)` определяют положение **ГЕОМЕТРИЧЕСКОГО ЦЕНТРА** стикера (а не его левого верхнего угла).
   - Это гарантирует, что вращение стикера и масштабирование происходят симметрично относительно точки привязки без паразитного смещения.
4. **Угол поворота `rotation_deg`:**
   - Измеряется в градусах в диапазоне `[0, 360)`.
   - Направление: **по часовой стрелке** вокруг геометрического центра стикера `(x_mm, y_mm)`.

---

## 3. Формат размещения стикера (Placement)

Каждый размещённый на холсте стикер описывается структурой:

```json
{
  "asset_id": "e4a1b8c2d9",
  "x_mm": 150.0,
  "y_mm": 105.0,
  "width_mm": 60.0,
  "rotation_deg": 15.0,
  "z": 1,
  "locked": false
}
```

### Поля:
- `asset_id` (`string`): Уникальный идентификатор стикера в каталоге.
- `x_mm` (`float`): Положение центра по оси X в миллиметрах.
- `y_mm` (`float`): Положение центра по оси Y в миллиметрах.
- `width_mm` (`float`): Физическая ширина стикера в миллиметрах. Допустимый диапазон: `[15.0, 150.0]` мм.
- `rotation_deg` (`float`): Угол поворота по часовой стрелке в градусах.
- `z` (`int`): Порядковый номер слоя (z-index). Большее значение означает отображение поверх других стикеров.
- `locked` (`bool`): Флаг блокировки от перемещения и изменений (в т.ч. алгоритмом авторасстановки).

> [!IMPORTANT]
> **Высота стикера (`height_mm`) НЕ хранится отдельно в структуре размещения!**
> Она всегда динамически вычисляется из исходных пропорций макета:
> `height_mm = width_mm * (height_px / width_px)`
> Это исключает искажение пропорций (растягивание) при редактировании.

---

## 4. Преобразование `px <-> mm`

Формулы прямого и обратного пересчёта:
- Масштаб отрисовки: `scale` (количество экранных пикселей на 1 миллиметр физического размера).
- `px = mm * scale`
- `mm = px / scale`

Функции пересчёта и геометрических операций реализованы изолированно:
- Бэкенд: `sticker_app/geometry.py`
- Фронтенд: `web/src/geometry/index.ts`

Поведение функций на обоих языках валидируется общим набором эталонных тестов (golden vectors):
`tests/golden/geometry.json` с допустимой погрешностью **не более 0.01 мм**.
