# jpeg2eps — Конвертер JPEG/PNG в векторный EPS для плоттера (с контуром реза `CutContour`)

Инструмент переводит растровые иллюстрации, стикеры и генерации ИИ (`.jpg`, `.jpeg`, `.png`, `.webp`) в чистый многослойный векторный формат **PostScript EPS (`%!PS-Adobe-3.0 EPSF-3.0`)** и автоматически строит гладкий внешний контур высечки со стандартным плашечным цветом **`CutContour`** (`100% Magenta`, `0.25 pt`).

Совместим с **Roland VersaWorks**, **Mimaki RasterLink**, **Graphtec Pro Studio**, **FlexiSIGN**, **Adobe Illustrator** и **CorelDRAW**.

---

## 1. Запуск в один клик через macOS Finder

Быстрое действие уже установлено в систему:
`~/Library/Services/Конвертировать в EPS (Плоттер).workflow`

1. Выделите один или несколько файлов `JPEG` / `PNG` (или целую папку) в **Finder**.
2. Нажмите **правой кнопкой мыши** → **Быстрые действия (Quick Actions)** → **Конвертировать в EPS (Плоттер)**.
3. Рядом с каждым исходным файлом появится готовый `.eps`, а macOS покажет уведомление о завершении.

---

## 2. Запуск через Терминал (CLI) и пакетная обработка

Глобальная команда установлена в `~/.local/bin/jpeg2eps`.

### Примеры команд

```bash
# Базовая конвертация одного файла (полная векторизация + CutContour с отступом 2.5 мм)
jpeg2eps sticker.jpg

# Пакетная конвертация всей папки с сохранением в отдельную папку
jpeg2eps ./input_stickers/ -o ./ready_eps/

# Задать точный физический размер стикера (например, 80 мм) и отступ контура реза (3 мм)
jpeg2eps sticker.jpg --size-mm 80 --offset-mm 3.0

# Контур реза вплотную по границе иллюстрации (без белого поля)
jpeg2eps sticker.jpg --offset-mm 0

# Режим "Только векторный контур реза": внутри остаётся исходный растр, снаружи векторный CutContour
jpeg2eps sticker.jpg --contour-only

# Дополнительно сохранить SVG для быстрого просмотра в браузере
jpeg2eps sticker.jpg --svg
```

---

## 3. Все доступные флаги CLI

| Флаг | По умолчанию | Описание |
| :--- | :--- | :--- |
| `-o`, `--output-dir` | Рядом с исходником | Папка для сохранения готовых `.eps` файлов |
| `--offset-mm` | `2.5` | Отступ линии реза `CutContour` вокруг стикера в мм (`0` — вплотную) |
| `--size-mm` | `100.0` | Физический размер большей стороны иллюстрации в мм |
| `--bg-tolerance` | `26.0` | Чувствительность удаления внешнего белого/однородного фона (`CIE LAB`) |
| `--keep-bg` | `Выкл` | Не вырезать внешний фон вокруг стикера |
| `--no-cut-contour` | `Выкл` | Не добавлять линию реза `CutContour` (только цветная векторизация) |
| `--contour-only` | `Выкл` | Оставить картинку внутри в растре, построив только векторный `CutContour` |
| `--speckle` | `8` | Фильтрация мелкого векторного мусора (в пикселях) |
| `--precision` | `6` | Точность группировки оттенков цвета от `1` до `8` |
| `--svg` | `Выкл` | Сохранять `.svg` копию рядом с `.eps` |
