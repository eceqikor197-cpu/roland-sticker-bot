Фаза 1: секреты и конфиг. Читай AGENTS.md.

Проблемы:
- xray_config.json с реальными данными прокси лежит в репозитории.
- В коде жёстко прописаны: ID администратора, IP 192.168.0.108, путь /home/crybaby/..., имя сервера в сообщениях, пароль по умолчанию для веб-админки.

Задачи:
1. Выполни `git rm --cached xray_config.json`, добавь его в .gitignore, создай xray_config.example.json с плейсхолдерами (<SERVER>, <UUID>, <PUBLIC_KEY>, <SHORT_ID>). Значения из исходного файла не копируй и не показывай.
2. Создай модуль config.py (dataclass или pydantic-подобный, без новых зависимостей): читает .env и окружение. Обязательные переменные: PLOTTER_BOT_TOKEN, ADMIN_IDS (список через запятую), ADMIN_WEB_PASSWORD. Если обязательная не задана, программа останавливается с понятным сообщением (fail fast), а не просто warning.
3. Необязательные с безопасными значениями: HOT_FOLDER_ROOT, WEB_HOST (по умолчанию 127.0.0.1), WEB_PORT, HOT_FOLDER_SMB_HOST и т.п.
4. Замени все жёсткие значения в telegram_bot.py и harvester/config.py на обращения к config. Тексты сообщений без имени сервера и без внутренних IP/путей (путь для Windows/Mac бери из настроек).
5. Обнови .env.example: все переменные с комментариями, без реальных значений.
6. Добавь тест, что при отсутствии обязательных переменных конфиг падает с понятной ошибкой.

Критерий готовности: grep по репозиторию не находит ни ID админа, ни IP, ни /home/crybaby, ни дефолтного пароля. Отчёт по формату AGENTS.md. Отдельно перечисли, что человек должен сделать вручную (перевыпустить прокси-ключи, очистить историю git).
