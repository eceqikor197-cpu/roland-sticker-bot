# Политика безопасности (Security Policy)

## Поддерживаемые версии

Обновления безопасности выпускаются для актуальной версии в ветке `main` (или `master`).

| Версия / Ветка | Поддержка безопасности |
| :--- | :--- |
| `main` / `master` | :white_check_mark: Поддерживается |
| < 1.0 (legacy) | :x: Не поддерживается |

---

## Сообщение об уязвимости

Мы серьёзно относимся к безопасности проекта `roland-sticker-bot`. Если вы обнаружили уязвимость или потенциальную проблему с безопасностью (например, утечку секретов, обход авторизации веб-админки, SSRF или инъекцию путей в Hot Folder плоттера):

1. **Не создавайте публичный GitHub Issue.**
2. Используйте **[GitHub Security Advisories](https://github.com/cryfcknbaby/roland-sticker-bot/security/advisories/new)** (приватный отчёт) для отправки подробностей.
3. Либо отправьте письмо автору на email: **`cryfcknbaby@gmail.com`** с темой письма:
   `[SECURITY] Уязвимость в roland-sticker-bot`.

### Что включить в отчёт

- Описание проблемы и потенциальное влияние (Impact).
- Шаги для воспроизведения проблемы (PoC, скрипт, запрос или шаги в Telegram/Web).
- Затронутые компоненты (`bot/`, `web/`, `storage/`, `harvester/`, `jpeg2eps.py` или конфигурация).
- Предлагаемое решение или патч (если есть).

### Сроки реагирования

- Подтверждение получения отчёта: **в течение 48 часов**.
- Первичная оценка и план исправления: **в течение 7 дней**.
- Публикация исправления (security advisory release) осуществляется после согласования с исследователем, нашедшим проблему.

Спасибо за помощь в обеспечении безопасности проекта!
