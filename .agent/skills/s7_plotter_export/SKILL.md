# Этап S7: Экспорт для плоттера

## Контекст и правила
- Читай `AGENTS.md`, `docs/COORDINATES.md`, `jpeg2eps.py` (ТОЛЬКО для чтения/импорта!).
- Самый ответственный этап: ошибка в масштабе или контуре тратит плёнку плоттера!
- **Файл для печати формирует ТОЛЬКО сервер** из `design JSON` (в мм) и оригинальных файлов. Фронтенд файлы для резки не генерирует.
- НЕ пиши в реальную папку Hot Folder во время тестов (используй `tmp_path`).
- Работа ведётся в ветке `feature/s7`.

## Задачи этапа

### Шаг 0. Разведка и фиксация контракта печати
- Изучи `jpeg2eps.py` и `harvester/processor/eps_pipeline.py`.
- Составь `docs/EXPORT.md`:
  - Имя спот-цвета реза (`CutContour`, 100% Magenta spot color).
  - Сквозной рез (`PerfCutContour` при необходимости).
  - Толщина абриса (0.25 pt / 0.75 pt).
  - Преобразование координат (Y вниз на экране -> Y вверх в PostScript: $Y_{eps} = PageHeight - Y_{canvas}$).
  - Правила нестинга и ширина рулона.
- Задай человеку вопросы: модель плоттера, версия VersaWorks, добавляет ли RIP метки совмещения автоматически. Дождись ответа.

### Шаг 1. Режим A: «Лист стикеров» (Nesting)
- Сборка списка уникальных стикеров из композиции с их физическими размерами `width_mm`.
- Раскладка стикеров на печатном листе без взаимных перекрытий через адаптер `sticker_app/export/nesting_adapter.py`.
- Генерация финального PostScript EPS/PDF с вектором реза спот-цветом `CutContour`.
- SVG допустим исключительно как отладочный предпросмотр, но не для плоттера.

### Шаг 2. Карта сборки (Assembly Map)
- Отдельный документ PDF масштаба строго 1:1 в мм.
- Отображает контур ноутбука и полупрозрачные пронумерованные контуры стикеров с порядком наклеивания, чтобы клиент мог наклеить их внахлёст точно как на холсте.

### Шаг 3. Калибровочный файл и проверка точности
- Генератор калибровочного файла: тестовый квадрат 100.0 × 100.0 мм с миллиметровыми засечками и метками совмещения.
- Тест «круг в круге» (`tests/app/test_export_accuracy.py`): сравнение центров стикеров в результирующем файле с `design JSON` (допуск не более 0.2 мм).
- Человек отправляет калибровочный файл на плоттер и подтверждает масштаб штангенциркулем (допуск $\pm 0.3$ мм).

## Критерий готовности
- Тесты геометрии экспорта зелёные.
- Калибровочный квадрат физически проверен на плоттере.
- Формат спот-цвета подтверждён RIP VersaWorks.
- Результаты зафиксированы в ветке `feature/s7`, обновлён `docs/PROGRESS.md`.
