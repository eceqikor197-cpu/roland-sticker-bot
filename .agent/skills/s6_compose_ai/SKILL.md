# Этап S6: Онбординг вкуса и «Собрать с помощью ИИ»

## Контекст и правила
- Читай `AGENTS.md`, `docs/RECOMMENDER.md`, `docs/COORDINATES.md`.
- Алгоритм авторасстановки должен быть детерминированным при одинаковом `seed`.
- Время генерации на бэкенде: **менее 3.0 секунд** для композиции из 80 стикеров.
- Работа ведётся в ветке `feature/s6`.

## Задачи этапа

### Часть 1. Бэкенд (`sticker_app/compose/`)
1. **Документ `docs/COMPOSE.md`:**
   - Описание математической модели и шагов эвристики размещения до написания кода.
2. **Эндпоинт `POST /api/v1/compose`:**
   - Вход: `{ object_id, profile (или liked), density: 0.3..1.0, seed: int, size_range_mm: [min, max], locked: Placement[], max_stickers: int }`
   - Выход: `{ placements: Placement[], metrics: { coverage_pct, overlap_pct, count, unique_topics } }`
3. **Алгоритм компоновки:**
   - Кандидаты: выборка через рекомендатор (S3) с MMR для высокого разнообразия тем.
   - Сетка объекта: дискретная матрица с шагом 2.0 мм.
   - Размещение от крупных к мелким: случайный выбор из $N$ пробных позиций с максимизацией приращения площади покрытия при соблюдении перекрытия с соседями (15–35% площади, жесткий максимум 60%).
   - Поворот: нормальное распределение $\mathcal{N}(0, \sigma=25^\circ)$.
   - Все стикеры строго внутри маски ноутбука (`allow_edge_overhang_mm = 0`).
   - Сохранение пользовательских заблокированных стикеров (`locked`).
   - Финальный проход: мини-стикеры заполняют остаточные пустоты.
4. **Тесты (`tests/app/test_compose.py`):**
   - 100 запусков со случайными seed: все стикеры внутри маски, нет паразитных выходов.
   - Фактическое покрытие в пределах $\pm 8\%$ от целевого `density`.
   - Время ответа $< 3.0$ с.

### Часть 2. Фронтенд (`web/src/components/Onboarding/` и `Compose/`)
1. **Модальное окно онбординга вкуса:**
   - Сетка из 12 карточек (`/api/v1/onboarding/cards`), выбор 3–5 стикеров, кнопка «Пропустить» (cold start).
   - Сохранение профиля в `localStorage`.
2. **Панель «Собрать с помощью ИИ»:**
   - Ползунок плотности (30% — 95%).
   - Кнопка «Сгенерировать», кнопка «Другой вариант» (новый seed).
   - Чекбокс «Сохранить заблокированные стикеры» (`send locked`).
   - Плавное анимированное появление стикеров на холсте (до 1.5 с суммарно).
   - Результат записывается в историю Zustand как **один атомарный шаг undo**.
3. **Отображение метрик:** процент покрытия, количество тем, число стикеров.

## Критерий готовности
- Полный сценарий: «онбординг -> генерация ИИ -> ручная правка трансформером -> Undo» работает без багов.
- Повторный запуск с одинаковым seed возвращает идентичную раскладку до сотых долей миллиметра.
- `python -m pytest -q`, `python -m ruff check .` и `npm test` зелёные.
- Результаты зафиксированы в ветке `feature/s6`, обновлён `docs/PROGRESS.md`.
