Проблемы: «Live-шпион» пересылает админу картинки и данные пользователей без уведомления; файлы хранятся 168 часов без объяснения.

Задачи:
1. В /start покажи краткое уведомление: файлы обрабатываются на сервере, хранятся N дней, администратор может их просматривать для обработки заказа. Кнопка/команда /privacy с этим текстом и /delete_my_data (удаляет задания и записи пользователя).
2. Параметры LIVE_SPY_DEFAULT (false по умолчанию) и JOB_RETENTION_HOURS в config. Админ включает слежение осознанно командой, и пользователи об этом уведомлены в /privacy.
3. cleanup_old_jobs вызывай по таймеру в фоновом потоке раз в час, а не при каждом входящем файле.
4. Тест на /delete_my_data (в tmp-каталоге).

Критерий готовности: см. формат отчёта в AGENTS.md.
