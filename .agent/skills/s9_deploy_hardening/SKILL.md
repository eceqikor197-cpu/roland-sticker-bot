# Этап S9: Усиление, развёртывание, юридический минимум

## Контекст и правила
- Читай `AGENTS.md`, `docs/PROGRESS.md`.
- Сервис развёртывается изолированно от фонового парсера: парсер в веб-контейнер НЕ включается.
- `harvester.db` монтируется строго в режиме `read-only` (`:ro`).
- Работа ведётся в ветке `feature/s9`.

## Задачи этапа
1. **Безопасность и защита от злоупотреблений:**
   - Ограничение частоты запросов (Rate Limiting) по IP на ресурсоёмкие эндпоинты (`compose`, `export`, `orders`, `designs`).
   - Жёсткий лимит на размер тела запроса (Payload Limit, до 2 МБ).
   - Заголовки безопасности: Content-Security-Policy (CSP), X-Frame-Options, X-Content-Type-Options.
   - Маскирование персональных данных клиентов (Telegram/email) в логах сервера.

2. **Контейнеризация (Docker & Caddy):**
   - Многоэтапный `Dockerfile`: сборка статики Vite/React + легковесный Python runtime для FastAPI.
   - `docker-compose.yml`:
     - Сервис `backend`.
     - Сервис `caddy` (автоматический HTTPS, отдача скомпилированной статики фронтенда, проксирование `/api/`).
     - Монтирование томов: `app_data` для `app.db`, `cache` для превью, `harvester_data` строго `:ro`.

3. **Резервное копирование:**
   - Скрипт горячего резервного копирования `scripts/backup_app_db.sh` через SQLite `.backup`.
   - Инструкция восстановления в `docs/DISASTER_RECOVERY.md`.

4. **Юридический минимум и Takedown (DMCA/авторские права):**
   - Страница «Условия использования и конфиденциальность» в веб-интерфейсе.
   - Форма и email для жалоб правообладателей.
   - В интерфейсе админки кнопка «Снять с публикации»: мгновенно устанавливает `takedown = 1` в `asset_meta` и исключает макет из всей выдачи каталога.

5. **Тестирование и релизная документация:**
   - e2e сценарий: запуск полного пути в Docker.
   - Обновление основного `README.md` с архитектурной схемой, списком переменных окружения и пошаговым чек-листом релиза.

## Критерий готовности
- `docker compose build && docker compose up -d` на чистой машине успешно запускает рабочий сервис.
- `python -m pytest -q` и `python -m ruff check .` зелёные.
- Результаты зафиксированы в ветке `feature/s9`, обновлён `docs/PROGRESS.md`.
