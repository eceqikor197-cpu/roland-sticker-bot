# Sticker Studio (бета)

Веб-редактор, в котором можно разложить стикеры на MacBook и посмотреть, как это будет выглядеть.
Работает в браузере на телефоне и компьютере, позже откроется из бота как Telegram Mini App.

Что умеет сейчас:
- MacBook Air 13", Pro 14", Pro 16": крышка и зона под клавиатурой, цвета корпуса;
- каталог из базы комбайна (`harvester.db`) с поиском и категориями;
- перетаскивание, масштаб, поворот, отражение, слои (выше/ниже), дубль, удаление, отмена/повтор;
- обрезка по краю корпуса, предупреждение, если стикер залезает на клавиатуру, тачпад или логотип;
- «✨ Заполнить» — стикер-бомбинг всей поверхности;
- сохранение раскладки со ссылкой и выгрузка PNG; черновик хранится в браузере.

## Запуск

```bash
pip install -r sticker_studio/requirements.txt
python -m sticker_studio.server   # http://<сервер>:8095
```

Переменные окружения: `STUDIO_HARVESTER_DB` (по умолчанию `bot_workspace/harvester/harvester.db`),
`STUDIO_DB` (сохранённые раскладки, по умолчанию `bot_workspace/studio/studio.db`), `STUDIO_HOST`, `STUDIO_PORT`.

База комбайна открывается только на чтение. Размеры поверхностей лежат в `static/surfaces.json` в миллиметрах.

Входа пока нет: любой, у кого есть адрес, может открыть редактор. Для беты держи его в локальной сети
или за туннелем; проверка подписи Telegram появится вместе с Mini App.
